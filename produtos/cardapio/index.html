Perguntas frequentes

Tem mensalidade?

Não. Você paga uma vez. Para colocar no ar, o guia mostra como usar o Netlify ou o GitHub Pages, que são grátis.

O cliente paga pelo site?

Não. O pagamento é combinado no WhatsApp, como você já faz hoje. O cliente só escolhe a forma de pagamento (Pix, cartão na entrega, dinheiro) e ela vem escrita no pedido.

Preciso saber programar?

Não. Você troca textos entre aspas em um bloco no topo do arquivo, como nome, item e preço. O guia mostra cada passo.

Funciona no celular do cliente?

Sim, foi feito primeiro para celular. O cliente não precisa baixar aplicativo.

Quantos itens posso colocar?

Quantos quiser. Recomendamos fotos leves para o cardápio abrir rápido.

Preciso ter um domínio (.com.br)?

Não. O serviço grátis já dá um endereço para você usar. Se quiser um domínio próprio, dá para ligar depois, pagando o domínio à parte.

Posso usar no site de um cliente meu?

Pode, um site por cliente. Só não pode revender o template.

E se eu travar na edição?
