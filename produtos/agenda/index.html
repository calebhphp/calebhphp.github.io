Dúvidas

Perguntas frequentes

Tem mensalidade?

Não. Você paga uma vez. Para colocar no ar, o guia mostra como usar o Netlify ou o GitHub Pages, que são grátis.

A agenda bloqueia o horário que já foi marcado?

Não. Ela mostra os horários em que você atende e manda o pedido para você confirmar no WhatsApp. Se o horário estiver ocupado, você sugere outro na conversa. A própria página avisa a cliente que a confirmação vem pelo WhatsApp.

Preciso saber programar?

Não. Você troca textos entre aspas em um bloco no topo do arquivo, como nome, preço e horário. O guia mostra cada passo.

Funciona no celular da cliente?

Sim, foi feita primeiro para celular. A cliente não precisa baixar aplicativo nem criar cadastro.

A cliente paga pelo site?

Não. Se você ligar o sinal, ela paga pelo app do banco com o QR Code ou o código Pix e manda o comprovante na conversa. O site não confirma o pagamento sozinho.

Trabalho sozinha. Serve?

Serve. Deixe a equipe vazia e a etapa “com quem” some da agenda.

Preciso ter um domínio (.com.br)?

Não. O serviço grátis já dá um endereço para você usar. Se quiser um domínio próprio, dá para ligar depois, pagando o domínio à parte.

Posso usar no site de um cliente meu?

Pode, um site por cliente. Só não pode revender o template.

E se eu travar na edição?

O guia mostra cada passo com exemplos. E você tem 7 dias de garantia: se não der certo, pede o reembolso pela Hotmart.
